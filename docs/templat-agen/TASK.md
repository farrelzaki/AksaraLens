# TASK.md

Catatan pekerjaan proyek. Setiap task punya tujuan, scope, kriteria selesai, risiko, dan rencana verifikasi.

> File pribadi (di-gitignore). Salin dari `docs/templat-agen/TASK.md` ke root repo.
> Saat kerja kelompok, **pembagian task ada di `KOLABORASI.md`**;
> file ini hanya berisi rincian task milikmu sendiri. Gunakan ID yang sama (mis. `T-01`).

## Status

- `[ ]` Backlog · `[~]` Sedang dikerjakan · `[x]` Selesai dan terverifikasi · `[-]` Dibatalkan (alasan dicatat)

## Prioritas

- `Tinggi`: menghambat pekerjaan lain atau sangat penting.
- `Sedang`: penting, tidak menghambat pekerjaan utama.
- `Rendah`: peningkatan yang bisa ditunda.
